Микросервис для управления балансами кошельков с шардированием.

Веб-приложение для просмотра партий игры Го в реальном времени (reverse‑engineering протоколов KGS).  
**Стек:** Go, PostgreSQL, Redis, Kafka, gRPC, Vue, Docker, GitHub Actions.  
**Особенности:** потоковая обработка, асинхронность, CI/CD.
